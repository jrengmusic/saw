{\bfseries{Purpose:}} SAW replaces {\ttfamily sed}, {\ttfamily grep}, and file-\/oriented {\ttfamily awk} with one deterministic, dry-\/run-\/first, atomic CLI tool. {\bfseries{Target End-\/\+User:}} CAROL agents (frontier and local models), CAROL scripts ({\ttfamily bin/\+carol}, JANITOR {\ttfamily fix.\+lua}), and ARCHITECT in the terminal. {\bfseries{Core Workflow:}} Preview exact matches or diffs by default, apply edits only with {\ttfamily -\/-\/apply -\/-\/expect N}, and reverse any applied transaction with {\ttfamily saw undo}.\hypertarget{md__s_p_e_c_autotoc_md157}{}\doxysubsection{\texorpdfstring{1.\+1 Scope and Authority}{1.\+1 Scope and Authority}}\label{md__s_p_e_c_autotoc_md157}
This document is the specification, and it governs every implementation detail. {\ttfamily Source/\+\+HELP.\+md} derives from this document and holds no independent authority. Where {\ttfamily Source/\+\+HELP.\+md} and this document disagree, this document is correct.

SAW operates on UTF-\/8 and raw-\/byte text files. SAW knows nothing about C++, CAROL, {\ttfamily doxygen-\/protocol}, or version-\/control commits. CAROL hooks enforce CAROL policy outside SAW.\hypertarget{md__s_p_e_c_autotoc_md158}{}\doxysubsection{\texorpdfstring{1.\+2 Locked ARCHITECT Decisions (Verbatim)}{1.\+2 Locked ARCHITECT Decisions (Verbatim)}}\label{md__s_p_e_c_autotoc_md158}

\hypertarget{md__s_p_e_c_autotoc_md164}{}\doxysection{\texorpdfstring{3. Core Principles}{3. Core Principles}}\label{md__s_p_e_c_autotoc_md164}

\begin{DoxyEnumerate}
\item {\bfseries{Dry-\/\+Run by Default:}} Every mutating verb previews changes and writes zero bytes unless {\ttfamily -\/-\/apply} appears on the command line ({\ttfamily "{}why not we make it always dry run by default. so destructive edit must be explicit. agents could still make mistake passing wrong args, so the default run is always safe and undoable"{}}).
\item {\bfseries{Explicit Two-\/\+Gate Write:}} {\ttfamily -\/-\/apply} always requires {\ttfamily -\/-\/expect N} on {\ttfamily replace}, {\ttfamily lines}, and {\ttfamily patch} ({\ttfamily "{}-\/-\/apply always requires -\/-\/expect N (dry-\/run prints N; mismatch writes 0 bytes)"{}}).
\item {\bfseries{Literal by Default:}} Search and replacement treat patterns as exact bytes unless {\ttfamily -\/r} enables regex ({\ttfamily "{}Literal default + -\/r regex (extend jam::\+\+Reg\+Exp with find\+Next/\+spans) + recursive dir walk skipping .git/.gitignore"{}}).
\item {\bfseries{Atomic All-\/or-\/\+Nothing Transactions:}} Every write is one atomic exchange or one atomic replace (§6.3). If file {\ttfamily k + 1} fails, SAW restores files {\ttfamily 0..k} immediately.
\item {\bfseries{Verified Reversible Undo:}} Every {\ttfamily -\/-\/apply} keeps the pre-\/edit file and the post-\/edit SHA-\/256 hashes in a bounded rolling cache ({\ttfamily "{}Rolling cache in app-\/data dir (cap 32 transactions, verifies post-\/edit hashes before restoring)"{}}).
\item {\bfseries{Deterministic Output:}} Parallel per-\/file work emits results sorted by normalized UTF-\/8 path, then line number, then byte offset.
\item {\bfseries{Exact Preservation:}} SAW preserves the line ending of each untouched line, trailing newline presence, symlink target resolution, and the metadata of each target: file mode, access control list, extended attributes. A target with more than one hard link is refused, because a swap breaks the link ({\ttfamily "{}Preserve each file\textquotesingle{}s LF/\+\+CRLF line endings and execute bit; follow symlinks to target (matching cast/\+scout)"{}}).
\end{DoxyEnumerate}

Rules:
\begin{DoxyItemize}
\item {\bfseries{Explicit file paths:}} Resolve relative paths against the current working directory. Resolve symbolic links to their final target with {\ttfamily std::\+filesystem::\+canonical}, which follows a link before it applies a {\ttfamily ..} that comes after it. Ignore rules (§4.4.\+1) never skip an explicit file path.
\item {\bfseries{Explicit directory paths:}} Walk in parallel with one item for each folder ({\ttfamily Paths::\+apply\+To\+Directories} and {\ttfamily Jobs::\+run\+Recursive}, using {\ttfamily std::\+filesystem::\+directory\+\_\+iterator}, one walk for all given directories). {\ttfamily Find} searches each file in the walk, also when several paths are given. The other verbs process the collected files in parallel via {\ttfamily Jobs::\+run}.
\begin{DoxyItemize}
\item Skip symbolic links.
\item Skip {\ttfamily .git} entries always.
\item Skip files and directories that the ignore rules (§4.4.\+1) exclude, unless {\ttfamily -\/-\/no-\/ignore} is set. Never descend into an excluded directory.
\item Skip dot-\/prefixed entries (hidden files and folders) unless {\ttfamily -\/-\/hidden} is set.
\item Sort all collected file paths in ascending byte-\/lexicographic UTF-\/8 order before emitting output or writing.
\end{DoxyItemize}
\item {\bfseries{Piped stdin:}} When no {\ttfamily path} argument is given and stdin is not a TTY:
\begin{DoxyItemize}
\item {\ttfamily find}, {\ttfamily lines} (read mode), {\ttfamily fields}, {\ttfamily replace} (dry-\/run mode), and {\ttfamily page} read stdin as a virtual file named {\ttfamily \texorpdfstring{$<$}{<}stdin\texorpdfstring{$>$}{>}}. {\ttfamily json} reads stdin as its input stream. {\ttfamily find}, {\ttfamily lines}, and {\ttfamily fields} stop the read when the line range or the first match decides the result.
\item Passing {\ttfamily -\/-\/apply} with stdin input fails with exit {\ttfamily 2}: {\ttfamily saw: cannot -\/-\/apply on stdin; specify file paths}. {\ttfamily write} takes its text from stdin and is the exception.
\item Empty stdin is an empty text. {\ttfamily find} and {\ttfamily fields -\/-\/match} exit {\ttfamily 1}. {\ttfamily lines}, {\ttfamily fields}, and {\ttfamily replace} exit {\ttfamily 0} and print nothing.
\end{DoxyItemize}
\item {\bfseries{Pipes:}} A path that names a pipe is read one time, to its end.
\item {\bfseries{Unreadable entries:}} {\ttfamily find} prints one error for each missing or unreadable file or folder, prints the matches of the readable files, and exits {\ttfamily 2}. {\ttfamily page} prints the readable files and exits {\ttfamily 1}. {\ttfamily json} reads the other files and exits {\ttfamily 2}. Every other verb fails on the first one before any output or write.
\item {\bfseries{No path and stdin is a TTY:}}
\begin{DoxyItemize}
\item {\ttfamily find} walks the current working directory {\ttfamily .}.
\item {\ttfamily replace}, {\ttfamily lines}, and {\ttfamily fields} fail with exit {\ttfamily 2}: {\ttfamily saw: missing path argument}.
\item {\ttfamily patch} reads from {\ttfamily -\/-\/file \texorpdfstring{$<$}{<}path\texorpdfstring{$>$}{>}} when given, otherwise fails with exit {\ttfamily 2}: {\ttfamily saw: patch requires stdin or -\/-\/file \texorpdfstring{$<$}{<}path\texorpdfstring{$>$}{>}}.
\end{DoxyItemize}
\item {\bfseries{{\ttfamily /\+dev/\+null} and a closed descriptor:}} {\ttfamily find} walks the current working directory {\ttfamily .}. {\ttfamily lines}, {\ttfamily fields}, and {\ttfamily replace} read an empty text.
\item {\bfseries{{\ttfamily write}:}} {\ttfamily write} reads its text from standard input. A terminal fails with {\ttfamily saw: write requires stdin}, exit {\ttfamily 2}.
\end{DoxyItemize}\hypertarget{md__s_p_e_c_autotoc_md171}{}\doxysubsubsection{\texorpdfstring{4.\+4.\+1 Ignore Rules}{4.\+4.\+1 Ignore Rules}}\label{md__s_p_e_c_autotoc_md171}

{\bfseries{Top level.}} The top level is the nearest ancestor of the walk root, the walk root included, that holds an entry named {\ttfamily .git}. When no ancestor holds one, the walk root is the top level.

{\bfseries{Sources, from highest to lowest precedence.}} Within one level, the last matching pattern decides the outcome.


\begin{DoxyEnumerate}
\item Each {\ttfamily .gitignore} file from the top level down to the directory of the path. A pattern in a lower-\/level file overrides a pattern in a higher-\/level file. Each pattern matches relative to the folder of its {\ttfamily .gitignore} file.
\item {\ttfamily \texorpdfstring{$<$}{<}top level\texorpdfstring{$>$}{>}/.git/\+info/\+exclude}, when that file exists.
\item The file that {\ttfamily core.\+excludes\+File} names.
\end{DoxyEnumerate}

\begin{DoxyEnumerate}
\item Read {\ttfamily \$XDG\+\_\+\+CONFIG\+\_\+\+HOME/\+git/\+config}. When {\ttfamily XDG\+\_\+\+CONFIG\+\_\+\+HOME} is not set or is empty, read {\ttfamily \$HOME/.config/\+git/\+config}.

\item A value that starts with {\ttfamily \texorpdfstring{$\sim$}{\string~}/} expands {\ttfamily \texorpdfstring{$\sim$}{\string~}} to {\ttfamily \$HOME}.

{\ttfamily }\hypertarget{md__s_p_e_c_autotoc_md233}{}\doxysubsection{\texorpdfstring{{\ttfamily 6.\+3 Two-\/\+Phase Commit Protocol}}{{\ttfamily 6.\+3 Two-\/\+Phase Commit Protocol}}}\label{md__s_p_e_c_autotoc_md233}
{\ttfamily }

{\ttfamily No lock exists. Ownership is one exclusive creation. The creation of a name that exists fails, so one process wins.}

{\ttfamily 
\begin{DoxyEnumerate}
\item {\bfseries{Plan phase (memory only):}} Read every target file, verify preconditions ({\ttfamily -\/-\/expect N}, hashes, bounds, non-\/binary), and compute planned buffers. Any error aborts with zero disk touches. A file whose access list or flags deny its deletion, in a folder that can be written, is refused here with {\ttfamily saw: write failed for \texorpdfstring{$<$}{<}path\texorpdfstring{$>$}{>}: overwrite failed; rolled back}, because no replace can take its place.
\item {\bfseries{Stage phase:}} Create {\ttfamily pending/\texorpdfstring{$<$}{<}tx-\/id\texorpdfstring{$>$}{>}.json} exclusively. The hex id is the microsecond of the second. When {\ttfamily pending/\texorpdfstring{$<$}{<}tx-\/id\texorpdfstring{$>$}{>}.json} or {\ttfamily undo/\texorpdfstring{$<$}{<}tx-\/id\texorpdfstring{$>$}{>}.json} exists, the id advances by 1 and the creation runs again. Then write the record, with one {\ttfamily pre\+Hash} and one {\ttfamily post\+Hash} for each file, and every {\ttfamily blobs/\texorpdfstring{$<$}{<}tx-\/id\texorpdfstring{$>$}{>}-\/\texorpdfstring{$<$}{<}i\texorpdfstring{$>$}{>}.blob}, in parallel. Flush each file. When the target and the cache are on one volume of a system with an atomic file exchange (mac\+OS), the blob holds the planned bytes and the metadata of the target. When the group of the target folder differs from the group of the cache, SAW creates the blob in the target folder and moves it. In every other case the blob holds the pre-\/edit bytes. A pending record that is not complete, or whose blobs do not all exist, is a transaction that changed no file. {\ttfamily undo -\/-\/list} does not list it, so a reader never sees a partial transaction.
\item {\bfseries{Commit phase:}} Release every mapping of a target. For each file {\ttfamily 0..M-\/1}:
\begin{DoxyItemize}
\item {\bfseries{Exchange:}} exchange the target and its blob in one system call. Thus the original file becomes the backup, and no byte of it is copied. Verify that the bytes of the blob equal the pre-\/edit bytes: a write by another process before the exchange is found here, and SAW exchanges the files back. Verify that the bytes of the target equal the planned bytes.
\item {\bfseries{Replace}} (no exchange on this volume or system, or the exchange fails): the blob holds the pre-\/edit bytes. Verify that the bytes of the target equal the pre-\/edit bytes. Write the planned bytes to a new {\ttfamily juce::\+\+Temporary\+File (target, Temporary\+File::\+use\+Hidden\+File)}, set the metadata, flush one time, and replace the target by one {\ttfamily rename} (Windows: {\ttfamily juce::\+\+File::\+replace\+File\+In}). A target that did not exist before the run must still not exist before the write. Verify that the bytes of the target equal the planned bytes.
\item After the last file, publish: move {\ttfamily pending/\texorpdfstring{$<$}{<}tx-\/id\texorpdfstring{$>$}{>}.json} to {\ttfamily undo/\texorpdfstring{$<$}{<}tx-\/id\texorpdfstring{$>$}{>}.json}.
\item On any failure at index {\ttfamily k}: restore files {\ttfamily 0..k-\/1} by the same exchange or replace, and verify each target and each blob. A target that another process changed after the exchange keeps that change, and the restore counts as failed, so its backup is kept. A blob that does not hold the pre-\/edit bytes is never discarded. When every restore holds, delete the record and the blobs and exit {\ttfamily 2}. When one restore fails, keep them and exit {\ttfamily 2} with {\ttfamily saw: write failed for \texorpdfstring{$<$}{<}path\texorpdfstring{$>$}{>}: \texorpdfstring{$<$}{<}reason\texorpdfstring{$>$}{>}; rollback failed for \texorpdfstring{$<$}{<}paths\texorpdfstring{$>$}{>}; backup kept in \texorpdfstring{$<$}{<}folder\texorpdfstring{$>$}{>}}.
\end{DoxyItemize}
\item {\bfseries{Prune phase:}} Delete the oldest published transactions beyond 32, each record before its blobs. The delete of the record is the claim: when the record is gone (an {\ttfamily undo} run moved it), SAW keeps the blobs.
\end{DoxyEnumerate}}

{\ttfamily {\ttfamily undo -\/-\/apply} creates {\ttfamily pending/\texorpdfstring{$<$}{<}tx-\/id\texorpdfstring{$>$}{>}.json} exclusively and moves {\ttfamily undo/\texorpdfstring{$<$}{<}tx-\/id\texorpdfstring{$>$}{>}.json} over it first. The process that wins the creation restores the files and deletes the record and the blobs. A failed restore moves the record back. A transaction that is already in the pending folder can belong to a running process, so {\ttfamily undo -\/-\/apply} refuses it with {\ttfamily saw: transaction \texorpdfstring{$<$}{<}tx-\/id\texorpdfstring{$>$}{>} is pending (pass -\/-\/force to restore it)} and exit {\ttfamily 2}. {\ttfamily -\/-\/force} restores it in place.}

{\ttfamily A process that stops between stage and commit leaves blobs in one of two states. The hash of the blob tells which one: {\ttfamily pre\+Hash} is a backup, so {\ttfamily undo} restores it; {\ttfamily post\+Hash} is a file that was not exchanged, so its target was not changed and {\ttfamily undo} does nothing to it. A blob with another hash, whose target has {\ttfamily pre\+Hash}, is also restored already. Any other hash is a corrupt transaction.}
