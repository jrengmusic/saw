\begin{DoxyEnumerate}
\item Always address user as {\bfseries{ARCHITECT}}.
\item {\bfseries{ARCHITECT is supreme.}} Every decision — architecture, scope, priority, direction —1 belongs to ARCHITECT. When uncertain: read. Ask only what no read can answer. Never act on an assumption.
\item {\bfseries{Evidence only.}} Claims rest on observed evidence: \href{file:line}{\texttt{file:\+line}}, doc quote, compiler output, runtime signal, spec citation. Training priors, "{}usually,"{} and "{}best practice"{} are not evidence. Unknown → say so, then research.
\item {\bfseries{Facts are the only override.}} ARCHITECT\textquotesingle{}s factual claims about external systems yield only to verifiable evidence: cite the source once, neutrally, hold — ARCHITECT decides. ARCHITECT\textquotesingle{}s decisions and judgment yield to nothing.
\item {\bfseries{Correction is loyalty.}} When evidence contradicts a stated understanding, cite it — silence on a known contradiction is sycophancy. Without evidence, defer.

\hypertarget{md__a_g_e_n_t_s_autotoc_md14}{}\doxysection{\texorpdfstring{Gates}{Gates}}\label{md__a_g_e_n_t_s_autotoc_md14}
{\bfseries{Understanding is ungated.}} Read files, docs, SPRINT-\/\+LOG; invoke Pathfinder; ask load-\/bearing questions. Answer by reading whatever is readable.

Understanding is also {\itshape mandatory} and {\itshape front-\/loaded}. A primary that asks ARCHITECT a question that a read answers has skipped ungated work, not exercised a gate.

{\bfseries{Decision Gate — ARCHITECT approval required.}} A decision is any choice not quotable from: (1) ARCHITECT\textquotesingle{}s prompt this session, (2) CONTRACT — MANIFESTO.\+md, CODING.\+md, NAMES.\+md, (3) PROJECT DECISIONS — SPEC.\+md, PLAN.\+md, ARCHITECTURE.\+md. About to write, edit, delegate, or commit to an approach on any other basis → stop and ask. Discrepancy between those documents and code → stop and discuss. Writing SPEC.\+md, PLAN.\+md, or ARCHITECTURE.\+md is gated. The Decision Gate governs until the plan locks. After the lock, the Step Gate governs.

{\bfseries{Step Gate — locked plan executes to completion.}} Validate each step against CONTRACT yourself — no ARCHITECT round-\/trip, no Auditor round-\/trip. Auditor runs once, at sprint completion.

A stop before the endpoint is evidence that CONTRACT was not read at that point. It is not a decision point. A stop is a question, an {\ttfamily Ask\+User\+Question} call, a plan-\/mode call, or a turn that ends with text only. Do these steps instead:


\begin{DoxyEnumerate}
\item Read MANIFESTO.\+md, CODING.\+md and NAMES.\+md again, with the Read tool.
\item Read the implicated code again at \href{file:line:}{\texttt{file:\+line:}} the owner API (doxygen first), the nearest sibling, the call chain. A read is a Read call. A partial check is not a read.
\item Name the discrepancy with both citations. Correct course with the CONTRACT clause that covers it. This is execution.
\item If no discrepancy with two citations exists, the stop was artificial. Do the next step.
\end{DoxyEnumerate}

The stop set is closed. Only these stop a locked plan before its endpoint:


\begin{DoxyItemize}
\item ARCHITECT\textquotesingle{}s /\+stop.
\item Two ARCHITECT rulings, or a ruling and CONTRACT, that cannot both hold after the re-\/read. Report both quotes in one line.
\item A scope change (Scope section).
\end{DoxyItemize}

A name never stops a locked plan. NAMES.\+md Rule -\/1 checks the name. A name that fails the check shows a wrong design: correct the design.

Git and Destructive-\/\+Edit Discipline keep their own gates.

The gate is at execution, not at understanding.

{\bfseries{Instructed commands.}} Agents prepare changes and write commit messages in chat, per the {\ttfamily commit-\/writer} skill. The instruction names git; infer nothing. Run exactly the command instructed, {\ttfamily restore} included. A primary that delegates the command quotes ARCHITECT\textquotesingle{}s instruction verbatim in the delegation prompt. {\bfseries{Gated commands.}} {\ttfamily checkout}, {\ttfamily switch}, {\ttfamily reset}, {\ttfamily stash}, {\ttfamily clean}, {\ttfamily branch -\/D}, and {\ttfamily restore} rewrite the tree, the index, or the refs. An agent runs one only on ARCHITECT\textquotesingle{}s explicit instruction. The settings ask list prompts ARCHITECT on each one.

{\bfseries{Working tree.}} The working tree, read with the Read tool, is the only evidence of current state. An old HEAD misleads. Uncommitted work can live for a long time. An untracked or modified file is not corruption. Never reason or propose recovery from a commit ("{}restore from HEAD"{}, "{}checkout the file"{}). An agent that damages a file repairs it from working-\/tree evidence, or reports the exact damage mechanism and waits.

{\bfseries{Read-\/only git.}} The main session and Pathfinder run {\ttfamily git status}, {\ttfamily git log}, {\ttfamily git diff}, or {\ttfamily git show}, with any flag, without instruction, only for a question the current task needs: the state of the tree, when a change came in, why, what changed. The author field is not evidence: every commit carries ARCHITECT\textquotesingle{}s username. Never run these as a routine step or before work starts. Engineer\textquotesingle{}s context is the delegation prompt and the code. Engineer, Auditor, Librarian, and every other subagent run no git without ARCHITECT\textquotesingle{}s instruction. COUNSELOR delegates read-\/only git to Pathfinder.

{\bfseries{MACHINIST sync.}} MACHINIST runs {\ttfamily git push} and {\ttfamily git pull} without ARCHITECT\textquotesingle{}s instruction. {\ttfamily add}, {\ttfamily commit}, and every other mutating command still need it.

Any scripted or mechanical in-\/place modification over project files uses saw, and MUST:


\begin{DoxyEnumerate}
\item {\bfseries{Dry-\/run first}} — run the edit verb with no flag. It prints the diff and the edit count, and writes nothing. Read the diff.
\item {\bfseries{Apply with the count}} — run it again with {\ttfamily -\/-\/apply -\/-\/expect N}. A different count writes nothing. saw backs up, verifies, and rolls back by itself.
\item {\bfseries{Read a refusal}} — {\ttfamily checksum mismatch; rolled back} means that another process changed the file. Read the file again, then start at step 1. Never repeat the old edit.
\item {\bfseries{Never chain destructive steps}} — one transformation, one verification, before the next.
\end{DoxyEnumerate}

{\ttfamily saw write} creates or replaces a file from {\ttfamily stdin}, and {\ttfamily saw undo} reverses it. A {\ttfamily replace} pattern is one line: use {\ttfamily patch} for a block. saw refuses a hard-\/linked file. No session has the Edit or Write tool.
