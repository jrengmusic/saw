# saw v0.0.1

Safe Atomic Writer

## What's New

- First release: SAW replaces sed, grep, and file-oriented awk with one deterministic, dry-run-first, atomic CLI tool.

## Platforms

| Platform | Architecture       | Format                            |
| -------- | ------------------ | --------------------------------- |
| macOS    | universal          | .pkg (signed, notarized)          |
| Windows  | x64                | .exe installer                    |
| Windows  | arm64              | .exe installer                    |

## Installation

macOS: open the .pkg. It installs `saw` on your PATH.

Windows: run the installer. It installs `saw.exe` and adds its folder to your user PATH.
